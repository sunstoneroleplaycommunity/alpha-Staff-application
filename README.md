# Sunstone RolePlay™ Application Website

GitHub Pages-ready staff application website for Sunstone RolePlay™.

## Publish to GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root` folder.
6. Save and wait for GitHub to publish.

## Important webhook note

This is a static GitHub Pages website. Any Discord webhook used in client-side JavaScript can be viewed by visitors in the browser. For a public website, rotate the webhook if needed and consider using a backend/proxy later.
